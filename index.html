Experiment 1: Hadoop Installation and Configuration Guide

Phase 1: Java Setup

1. Install Java 11

Enable the universe repository (required on newer Ubuntu versions), update package lists, and install OpenJDK 11:

sudo apt install software-properties-common
sudo add-apt-repository universe
sudo apt update
sudo apt install -y openjdk-11-jdk

2. Set Java 11 as the active version

Since Java 25 is currently installed, your system defaults to it. Tell Ubuntu to use Java 11 instead:

sudo update-alternatives --config java
java -version

3. Set JAVA_HOME for Hadoop

echo 'export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64' >> ~/.bashrc
echo 'export PATH=$PATH:$JAVA_HOME/bin' >> ~/.bashrc
source ~/.bashrc

Phase 2: User and SSH Configuration

1. Create a Hadoop User:

sudo addgroup hadoop
sudo adduser --ingroup hadoop hadoopusr
sudo usermod -aG sudo hadoopusr

2. Install SSH and switch user:

sudo apt-get install openssh-server
su - hadoopusr

3. Generate and authorize the SSH key, then verify the connection:

ssh-keygen -t rsa -P "" -f ~/.ssh/id_rsa
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
sudo service ssh start
ssh localhost
exit

Phase 3: Downloading and Placing Hadoop

1. Download Hadoop 3.3.6:

cd ~
wget https://downloads.apache.org/hadoop/common/hadoop-3.3.6/hadoop-3.3.6.tar.gz

2. Extract, rename, and move the folder:

tar -xzvf hadoop-3.3.6.tar.gz
sudo mv /home/hadoopusr/hadoop-3.3.6 /usr/local/hadoop

3. Clean up the downloaded archive and change directory ownership:

rm hadoop-3.3.6.tar.gz
sudo chown -R hadoopusr:hadoop /usr/local/hadoop

Phase 4: Setting Environment Variables

Open your .bashrc file (nano ~/.bashrc) and add the following environment variables:

export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export HADOOP_HOME=/usr/local/hadoop
export HADOOP_INSTALL=$HADOOP_HOME
export HADOOP_MAPRED_HOME=$HADOOP_HOME
export HADOOP_COMMON_HOME=$HADOOP_HOME
export HADOOP_HDFS_HOME=$HADOOP_HOME
export YARN_HOME=$HADOOP_HOME
export HADOOP_COMMON_LIB_NATIVE_DIR=$HADOOP_HOME/lib/native
export PATH=$PATH:$HADOOP_HOME/bin:$HADOOP_HOME/sbin

Save the file and apply the changes:

source ~/.bashrc

Phase 5: Configure Hadoop XML Files

Navigate to the Hadoop configuration directory:

cd /usr/local/hadoop/etc/hadoop

1. Set JAVA_HOME in hadoop-env.sh (nano hadoop-env.sh):

export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64

2. Create HDFS Directories for NameNode and DataNode:

mkdir -p /home/hadoopusr/hdfs/namenode
mkdir -p /home/hadoopusr/hdfs/datanode

3. Configure core-site.xml (nano /usr/local/hadoop/etc/hadoop/core-site.xml):

<configuration>
  <property>
    <name>fs.default.name</name>
    <value>hdfs://0.0.0.0:9000</value>
    <description>The default file system URI</description>
  </property>
</configuration>

4. Configure hdfs-site.xml (nano /usr/local/hadoop/etc/hadoop/hdfs-site.xml):

<configuration>
  <property>
    <name>dfs.replication</name>
    <value>1</value>
  </property>
  <property>
    <name>dfs.name.dir</name>
    <value>file:///home/hadoopusr/hdfs/namenode</value>
  </property>
  <property>
    <name>dfs.data.dir</name>
    <value>file:///home/hadoopusr/hdfs/datanode</value>
  </property>
</configuration>

5. Configure mapred-site.xml (nano /usr/local/hadoop/etc/hadoop/mapred-site.xml):

<configuration>
  <property>
    <name>mapreduce.framework.name</name>
    <value>yarn</value>
  </property>
</configuration>

6. Configure yarn-site.xml (nano /usr/local/hadoop/etc/hadoop/yarn-site.xml):

<configuration>
  <property>
    <name>yarn.nodemanager.aux-services</name>
    <value>mapreduce_shuffle</value>
  </property>
</configuration>

Phase 6: Formatting, Starting, and Managing the Cluster

1. Format the NameNode (Initialize the file system for the first time):

hdfs namenode -format

2. Start Storage Services:

start-dfs.sh
start-yarn.sh

3. Verify Running Daemons:

jps

4. View Dashboards:

Access the Hadoop cluster overview via a web browser at: localhost:9870

Access YARN cluster application metrics at: localhost:8088
